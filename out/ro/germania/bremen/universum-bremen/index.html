Universum® Bremen

Vezi pe hartă

Universum® Bremen este un centru științific în forma unei balene gigantice. Oferă expoziții interactive despre natură, oameni și tehnologie pentru toate vârstele.

Informații

  • Deschis în 2000, situat pe campusul Universității din Bremen.
  • Fațada imită forma unei balene și este realizată din oțel inoxidabil.
  • Peste 300 de experimente pot fi încercate interactiv.
  • Aproximativ 350.000 de persoane vizitează centrul științific anual.
  • Expoziții speciale care se schimbă regulat completează oferta.

Statuia Muzicanților din Bremen

Primăria Bremen

Primăria din Bremen din Piața Pieței este un exemplu remarcabil al Renașterii Weser și, împreună cu Roland, este Patrimoniu Mondial UNESCO din 2004. Este una dintre cele mai importante primării din Germania.

Roland din Bremen

Roland din Bremen este o statuie de piatră de 5,50 metri înălțime din Piața Pieței, simbol al libertății orașului Bremen. Este considerată cea mai veche statuie Roland păstrată din Germania.

Catedrala din Bremen

Catedrala Sfântul Petru din Bremen este o biserică protestantă cu o istorie care datează din secolul al VIII-lea. Cu cele două turnuri marcante, ea domină silueta centrului vechi al Bremei.
